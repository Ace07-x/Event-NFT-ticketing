# Project Technologies

This event ticketing application is a decentralized application (dApp) built with the following technologies:

## Smart Contract Development (Backend)
- **Solidity**: The primary programming language used for writing the smart contracts (`v0.8.28`).
- **Hardhat**: The development environment and testing framework used to compile, deploy, and test the Ethereum software.
- **OpenZeppelin Contracts**: A library of secure, standard smart contract components used for building the contracts.

## Frontend Development
- **Vite**: The build tool and development server, chosen for its speed and optimal developer experience.
- **Vanilla Web Technologies**: The UI is built using standard **HTML**, **CSS**, and **JavaScript** without any heavy UI frameworks (like React or Vue).
- **Ethers.js**: A library (`v6.17.0`) used to interact with the Ethereum blockchain and the deployed smart contracts from the frontend application.

## General Tooling
- **Node.js & npm**: Used for package management across both the smart contract and frontend environments.
